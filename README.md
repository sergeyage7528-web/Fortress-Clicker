# Fortress Clicker

Первый рабочий вертикальный прототип Android-игры на Godot 4.

Откройте `project.godot` в Godot 4.7 или новее и нажмите Run. Для Android в Project Settings уже включена портретная ориентация; после установки Android export template экспортируйте обычным способом в APK/AAB.

В прототипе есть десятиволновые стадии с боссом, тапы по монстрам для выстрелов башни, автоматические защитники, смерть бойцов до конца стадии, улучшения, магазин четырёх героев и сохранение прогресса в `user://fortress_progress.cfg`.

## Проверка проекта

Проект проверен в Godot 4.7.1.
Для запуска откройте `project.godot` и нажмите Run.
